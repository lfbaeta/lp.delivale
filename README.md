# Delivale — Seu delivery, sua gestão

Landing page em português para apresentar o catálogo digital, a organização de pedidos e a vitrine Marketplace da Delivale.

## Executar localmente

Abra `index.html` em um navegador ou sirva o diretório com qualquer servidor estático.

## Publicação

`dist/` contém a página de entrada configurada para hospedagem estática no OpenAI Sites. O código fonte também está no GitHub em https://github.com/lfbaeta/lp.delivale.

A calculadora é ilustrativa e compara o percentual informado pelo visitante às vendas estimadas. Valores e condições da vitrine devem ser confirmados com a equipe Delivale.
